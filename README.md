Я работал с серверами Linux (Ubuntu, Debian) и Windows Server в различных средах (on-premises, облако Azure). 
Я настроил серверы для веб-приложений (Nginx, Apache), баз данных (PostgreSQL, MySQL, Redis) и серверы аутентификации (FreeIPA, Active Directory).
Также я конфигурировал и поддерживал системы мониторинга и логирования с помощью Grafana и Wazuh.

Я отвечал за автоматизацию развертывания и настройки серверов с помощью Ansible   

Я внедрил CI/CD с Jenkins и GitLab CI, обеспечивая быстрые и безопасные обновления.

Я контролировал безопасность и управление логами с помощью Wazuh и SIEM для выявления инцидентов безопасности.


Я настроил CDN и reverse proxy (Nginx) для снижения нагрузки на серверы приложений.

 Я работал с PostgreSQL, MySQL, Redis и MongoDB. 
 Для масштабируемости я настроил репликацию Master-Slave в PostgreSQL. 
 Также я настроил кеширование с помощью Redis для ускорения частых запросов. 

 Я настроил конвейер CI/CD с Jenkins и GitLab CI, включая следующие шаги:**
 Линтинг и модульное тестирование (Pytest, Jest, JUnit)
Создание образа Docker и его отправка в реестр (Docker Hub, ECR, GitLab Registry)
Автоматизированное развертывание в Kubernetes с помощью Helm
 Мониторинг после развертывания с помощью Prometheus


 Я написал руководства по развертыванию полных стеков, включая приложения Nginx, PostgreSQL и Node.js.

Разработали сценарий Ansible для повышения безопасности маршрутизаторов MikroTik, включая настройку правил брандмауэра, отключение незащищенных служб, реализацию строгой аутентификации и включение централизованного ведения журнала. Данный проект обеспечивает расширенную защиту от угроз и упрощенное управление сетевым оборудованием.
